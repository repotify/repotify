# Getting help

- **Questions and ideas:** open an issue and describe what you are trying to do.
- **Bugs:** use the [bug report form](https://github.com/repotify/repotify/issues/new?template=bug_report.yml). Include the
  commands you ran, what Repotify printed, your agent and `repotify --version`.
- **A skill that should be in the catalog:** use the [submission form](https://github.com/repotify/repotify/issues/new?template=catalog_submission.yml).
- **Security problems or a malicious catalog item:** never in public. Use a
  [private advisory](https://github.com/repotify/repotify/security/advisories/new); see [SECURITY.md](SECURITY.md).
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).
